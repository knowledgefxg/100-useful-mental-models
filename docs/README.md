# 100 个思维模型

## 给思考多一些工具，给判断多一点依据。

买东西越挑越乱？听了很多道理，却不知道该不该信？一次没做好，就开始怀疑自己？这份手册从这些身边的小事讲起，介绍 100 个可以帮助思考的办法。

你不需要学过心理学、统计学或哲学，也不用背那些长名字。先把它们当成一副副新眼镜：遇到一件想不明白的事，换个角度看看，可能就能找到下一步。

## 怎么读

- **从一个实际问题出发**：先选与你手头问题相关的一页，读完尝试其中一个动作。
- **沿主题阅读**：目录分成八组，同组概念可以互相补充。
- **顺着看下去**：每页会链接几个相关模型，想深入时再点开，不必一次全读。
- **回到现实验证**：记下你依据模型作了什么决定，事后检查它是否真的有帮助。

## 每页有什么

每篇都从一句容易理解的话开始，接着慢慢展开：

- **定义**：从熟悉的情境切入，穿插一两句规范定义，再用通俗的话解释；有明确提出者的理论或框架会作相应说明。
- **举个身边的例子**：用租房、购物、学习、工作和相处里的完整场景说明。
- **换个场景看看**：再给一个例子，帮助你知道它不只适用于一种情况。
- **可以这样试**：讲清什么时候用得上，再给三个可以照做的动作。
- **别用过头了**：说说常见误用，免得学会一句话就什么都往上套。
- **花一分钟试试**：一个短练习，把读过的内容和自己的事情连起来。

你可以只看当下需要的部分。看懂一个例子、试一个动作，就已经有收获，不必先把整套内容记住。

## 关于这份内容

本手册收录 100 个思维模型，包含中文解释、示例与行动步骤。各篇的“来源与延伸”提供对应的百科条目、作者资料或可信机构说明，方便继续阅读；没有合适资料时不显示该栏目。示例为方便理解而设置，不是真实案例报道。

这些模型包含科学概念、哲学思想、经验法则与商业框架，证据基础与用途各有不同。使用时请结合对应页面说明的适用边界。
